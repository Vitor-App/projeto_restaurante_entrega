# Sistema de Registro de Pedidos

Projeto avaliativo em Java para registrar pedidos de uma lanchonete e apresentar um relatório consolidado ao final do processamento.

## Escopo

A implementação contempla os requisitos obrigatórios: entrada de dados pelo teclado, cadastro de vários pedidos, validação de valores maiores que zero, repetição controlada pelo operador, contador, acumulador, operações matemáticas e relatório final com quantidade de pedidos, valor total, ticket médio, maior compra e menor compra.

Os desafios opcionais não fazem parte desta versão, conforme definido para a entrega.

## Evolução do projeto

A solução será desenvolvida em incrementos independentes, cada um registrado no histórico do Git:

1. Documentação do algoritmo e do escopo.
2. Estrutura inicial do projeto Java.
3. Cadastro e validação dos pedidos.
4. Relatório final de vendas.
5. Testes e documentação de execução.

Consulte [ALGORITMO.md](ALGORITMO.md) para a lógica planejada.
